# Changelog

## 0.1.0 — 2026-10-16 (first release)
- Started from R1 NOC Wall 0.3.9 (same dashboard engine, editor, alerts, HTTPS, backup, in-place upgrade and packaging), renamed to **SZ-AI NOC Wall**.
- Goal: a NOC wall for **RUCKUS AI** (ruckus.cloud/ai) first, then **RUCKUS SmartZone** controllers.
- Live data now comes from RUCKUS AI: SmartZone controllers (with onboarding state), zones and switch groups, every AP and switch, open incidents as alarms and Intent AI recommendations. Sign in with an Application Token (Administration → Developers → Application Tokens); RUCKUS One API keys do not work.
- New RUCKUS AI widgets (controllers healthy, controller table, APs by controller, Intent AI) and new default screens (Overview, Zones, Switches, Intent AI). Per-client lists, DPSK, guests, Wi-Fi calling and switch-port widgets have no RUCKUS AI data source.
- **Both sources at once**: RUCKUS AI and SmartZone each have their own on/off (and each controller its own), both are polled side by side, and each screen shows exactly one source (a **Data** box on the screen; the preferred source for the rest). History, alerts, stock layouts and reports follow the source.
- **Data source choice**: a wall can read RUCKUS AI and/or SmartZone controllers directly (new `lib/sz.js`: public API client with API-version and API-key-style detection, paging, per-controller TLS setting). SmartZone reads zones, APs (status, model, firmware, IP, clients, channels), WLANs and controller info (field names confirmed on a SmartZone 7.2); clients and alarms are mapped but unconfirmed; the widget picker, presets and stock screens follow the chosen source. `scripts/widget-check.js --source smartzone` measures a controller.
- Widgets and presets are split by source: each carries the sources it works for, the editor offers "For this wall / RUCKUS AI / SmartZone / Everything", picker buttons are tagged "RUCKUS AI only" / "SmartZone only", and the stock screens of each source are separate presets.
- SmartZone: DPSK users (one pool per WLAN; the passphrase is never copied), VLAN pools, Wi-Fi calling policies, controller CPU / memory / disk (new widgets *Controller CPU / memory / load*), alarm counts by severity, alarm and client rows, AP radio width / noise / airtime, and **switches and switch ports** through the Switch Manager API (all confirmed against a live SmartZone 7.2 with an AP, a client and ICX switches); guest passes and the switch event log; the SmartZone stock layout also gains *Switches* and *Guests* screens, and only 103 widget types remain hidden for SmartZone (RUCKUS AI only 49, identity groups 27, Wi-Fi calling clients 22, a few client fields and 6 GHz trends); the SmartZone stock layout gains *Access* and *AP radios* screens and about 120 more widgets work for it. New radio measures *avg noise floor* and *avg airtime*.
- The editor's connection panel is "RUCKUS AI connection" (client ID, secret, optional tenant ID, region). MSP and per-customer modes are hidden.
